# Storeva public showcase — media safety checklist

Only publish media captured or approved for public marketing.

Before adding images/video:
- Hide or replace all customer names, phone numbers, addresses and messages.
- Remove tokens, credentials, API URLs with secrets, internal admin routes and private data.
- Use test merchants/products or explicitly approved public catalog content.
- Check browser tabs, developer console, URL bar and notifications in screen recordings.
- Do not copy application source files or its Git history into this repository.

Recommended public assets:
- `assets/screenshots/storefront.png` — public-facing storefront
- `assets/screenshots/merchant-products.png` — sanitized product management screen
- `assets/screenshots/order-flow.png` — sanitized customer order flow
- `assets/demo/storeva-demo.mp4` — short edited demonstration if approved

Use only asset filenames that really exist; never leave broken Markdown image references.
